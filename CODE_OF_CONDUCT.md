# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive, assume good faith, welcome newcomers, keep discussions
about the work. Harassment, personal attacks and discriminatory remarks are not tolerated anywhere
in the project's spaces (issues, pull requests, discussions).

To report a problem, contact the maintainer privately through the repository's GitHub profile. Reports
are handled confidentially. Maintainers may edit or remove contributions and comments that break
these rules, and may temporarily or permanently ban repeat offenders.
